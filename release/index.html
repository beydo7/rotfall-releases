So startest du ROTIUM

ZIP laden

Oben auf „Für Windows laden“ klicken.

Entpacken

Rechtsklick auf die ZIP-Datei → „Alle extrahieren“.

ROTIUM.exe starten

Warnt Windows („Der Computer wurde geschützt“): „Weitere Informationen“ → „Trotzdem ausführen“.

Neue Version? Einfach die neue ZIP entpacken und die alte löschen. Dein Fortschritt liegt getrennt vom Spiel und bleibt erhalten.
